## 它做什么

`wizard` 生成一个交互式 bash 脚本，带人一步步走完一套手工流程：接入第三方服务、跑一次性迁移、把项目从状态 A 搬到状态 B。它打开每个网址，说清点什么、复制什么，收集返回的值，并写进 `.env` 文件和 GitHub Actions 密钥。

[代理（agent）](https://www.aihero.dev/ai-coding-dictionary/agent)写脚本，从不运行它。你在自己的机器上运行。向导是一个程序，不是一列说明。脚本按顺序执行每一步，并保留你输入的值。你要做的是点、粘贴、按回车。

## 什么时候用它

你可以打 `/wizard`，代理也能自己取用它。当它撞上只能由你来做的一步（一个它造不出来的密钥、一个它点不了的后台），它会给你造一个向导，而不是把说明写进聊天里，让它们滚走。

当下一个阻碍是一趟后台操作之旅时用它：

| 情形 | 向导做什么 |
| --- | --- |
| 新开发者要配好六个服务，应用才能启动 | 按顺序打开每个后台，收集密钥，写进 `.env` 和 CI |
| 一次性迁移需要按特定顺序拨开关 | 把不可逆的步骤排在确认关卡之后 |
| 项目要从状态 A 搬到状态 B，只搬一次 | 带你走完这次转换，并报告它做不了的部分 |
| 你正要把这些步骤写进 README | 改写成可执行的版本，某一步过时时它会明显失败 |

不要用它来*决定*建什么；那个用 [grill-with-docs](https://aihero.dev/skills-grill-with-docs) 和 [to-spec](https://aihero.dev/skills-to-spec)。

## 前提条件

生成向导不需要任何前提。它写出的向导跑在 bash 上，在某个阶段要设置 GitHub 密钥或变量时使用 `gh`。如果 `gh` 缺失或未通过鉴权，运行不会失败。那个阶段会显示一条警告，收尾总结会告诉你哪些需要手工设置。

## 阶段

**阶段**是一个屏幕上的一件聚焦任务。脚本在阶段之间清屏，所以溢出屏幕的阶段会丢掉滚出去的那部分。你按依赖顺序编写阶段，并设置 `TOTAL_STAGES`，它驱动进度显示。

[技能（skill）](https://www.aihero.dev/ai-coding-dictionary/skill)在写任何脚本之前先理清流程范围。它去读仓库，而不是张嘴就问：`.env*`、`docker-compose*`、框架配置，以及 `.github/workflows/` 里每一处 `secrets.*` / `vars.*` 引用。那些引用里的每一个都是向导必须产出的值。然后它把有序的阶段清单给你确认。只有在你确认之后，它才把每个阶段映射到人要走的确切路径（“后台 → Developers → API keys → Reveal test key → 复制”）。凡是它不知道当前界面的地方，它会问你或者查文档，而不是编出点击步骤。

对每个收集的值，理清范围时就要决定它去哪：

| 目的地 | 什么时候 |
| --- | --- |
| 只进 `.env` | 本地开发需要，CI 不需要 |
| GitHub 密钥 | CI 要读，而且是敏感的 |
| GitHub 变量 | CI 要读，而且是公开的 |
| `.env` 和密钥都写 | 本地开发和 CI 都需要 |
| 哪都不写 | 这个阶段是纯操作：拨了个开关、升了个套餐 |

## 模板已经把交互做好了

[模板](https://github.com/mattpocock/skills/blob/main/skills/engineering/wizard/template.sh)提供了整套体验：带剩余时间的进度、确认关卡、跨平台打开网址（包括 WSL）、密钥隐藏输入、幂等的 `.env` 写入、`gh secret` / `gh variable` 写入，以及收尾总结它不得不跳过的所有东西。`STAGES` 标记之上的所有内容是一个固定库，每个向导里都一样，绝不手工改动。因为库从不变化，每个向导的行为都一致。每个向导唯一的工作就是理清流程范围并写出它的阶段。

写向导的代理从不端到端运行它，因为脚本会打开浏览器并停下等人输入。代理改为静态检查：`bash -n`、有的话跑 `shellcheck`，以及一条追踪，确认每个值都落到理清范围时说的位置，每个 `set_secret` 名字都与 CI 里真实的 `secrets.*` 引用相符。所以第一次运行是你的，那次运行就是测试。

## 默认一次性

| 你手上是什么 | 脚本怎么处理 |
| --- | --- |
| 一次性迁移、个人配置、你再也不会重复的转换 | 存到临时路径或 `scripts/` 下，跑一遍，删掉 |
| 仓库里下一个人也会需要的配置路径 | 提交它，并从 README 链接过去，好让他们跑脚本而不是再问一遍代理 |

## 常见问题

**我的 API 密钥会进到模型的上下文里吗？**

不会。代理写脚本，不运行它。你自己运行脚本，它用终端隐藏输入收集密钥，直接写进 `.env` 或 `gh secret`。向导是一个命令行工具，模型没有接在上面。这只对向导在运行时收集的值成立。如果你在理清流程时把密钥粘进聊天，那它就跟任何其他粘贴的文本一样进了[上下文（context）](https://www.aihero.dev/ai-coding-dictionary/context)。

**我能回去改一个打错的值吗？**

运行中途不行。没有后退按钮。阶段是往前跑的，第 3 步答错就意味着 Ctrl-C 重跑。重跑很便宜，因为已经写进 `.env` 的值会作为默认值再给你，所以你一路按回车经过做对的阶段，只重打错的那个。用户在发布当周就提了这个需求，目前仍然未解决：“很喜欢！不过有一件事，有办法回去改正已经输入的内容吗？”

**它知道我配好了什么吗？**

部分知道，比发布时的反应以为的要少。它问之前先读仓库（你的 `.env` 文件、`docker-compose`、框架配置、CI 里的 `secrets.*` 引用），所以它针对的是缺失的值，而不是像 README 那样从零开始。它不做的是去检查第三方服务。如果 `.env` 里已经有某个密钥，向导会把它作为默认值给你，回车就保留；如果你已经建好了 Stripe 账户但从没保存密钥，向导还是会把你送到后台去取。

**它在工作流里处于什么位置，拷问和规格说明之后吗？**

不在什么特定位置。它是一个独立技能，不是链条上的一步。常见的猜测是 `/grill-with-docs → /to-spec → /wizard`，这个顺序没问题，但触发条件是出现一套手工流程，而那可能发生在任何时候：开工之前、构建中途，或者交付很久之后。它也能当发现工具用。理清范围会在你投入工作之前找出一个任务隐藏的前提，比如你没想到的三个 API 密钥。

**它在 Claude Code 之外能用吗？**

脚本能。它是纯 bash，无论哪个 [harness](https://www.aihero.dev/ai-coding-dictionary/harness) 生成的，跑起来都一样。技能本身是模型调用的，所以到处都能列出：在 Claude Code 里打 `/wizard`，在 Codex 里打 `$wizard`，或者干脆描述你卡住的那个配置。模型调用也让它可以避开 [#693](https://github.com/mattpocock/skills/issues/693)：那里 Claude 的桌面版和网页版会把*用户调用*的技能从[模型（model）](https://www.aihero.dev/ai-coding-dictionary/model)的清单里去掉，并报成未安装。

**它以前不是用户调用的吗？**

是。现在改成模型调用了，所以代理撞上只能由你做的一步时会主动取用它。你以前能做的都没失效。模型调用让代理也能调用这个技能，和你一样，所以 `/wizard` 行为如旧。这次改动修掉了一个失败：以前代理在构建中途撞上凭据问题，会往聊天里倒六个编号步骤让你手工照做。现在它写一个向导。

**它以前在 `in-progress/` 里。现在在哪？**

从 v1.2 起在 `engineering/`。它从测试分组毕业，现在随插件一起发布，所以跟其他已收录的技能一起来，不需要单独安装。毕业时它的行为没有变化。

## 它在生效的表现

- 在任何脚本存在之前，你先看到有序的阶段清单和每个阶段产出的值，并被要求确认。
- 每个网址都先打开，然后再索取那个页面上的值。你从不会被要求粘贴一个还没被送去获取的东西。
- 密钥是盲打的。敏感内容不会回显进你的屏幕滚动记录。
- 每个阶段一屏装得下。你还需要的部分没有被滚走。
- Ctrl-C 重跑能从你中断的地方继续，把已保存的值作为默认值给出。
- 最后一块屏幕列出它写了什么，并单独列出它做不到、需要你手工完成的部分。

## 它在哪里合用

`wizard` 是一个随时可用的独立技能，站在自动化停止、必须由人来点击的那条线上。最亲近的邻居是 [setup-matt-pocock-skills](https://aihero.dev/skills-setup-matt-pocock-skills)，因为两者都是为了让仓库进入可用状态。那个配置这套技能，`wizard` 则为其他一切生成配置路径。它也和 [implement](https://aihero.dev/skills-implement) 配合：当一次构建交付了需要凭据或手工切换的功能时，向导覆盖只有人能做的那几步。不确定当下该用哪个技能时，[ask-matt](https://aihero.dev/skills-ask-matt) 会帮你导航。
