description: 以高可信度的一手资料为依据调查一个问题，并把结论保存成仓库里的 Markdown 文件。当用户希望调研某个主题、收集文档或 API 事实，或把阅读工作交给后台代理时使用。
---

启动一个**后台代理**去做调研，这样它读资料时你可以继续工作。用全新的上下文窗口启动它。

它的任务是：

1. 以**一手资料**（官方文档、源码、规格说明、第一方 API）为依据调查问题，而不是依赖对这些资料的二次转述。每一条结论都要追回到拥有它的来源。
2. 把结论写进一个 Markdown 文件，并为每条结论标注来源。
3. 保存到仓库已经在放这类笔记的位置；沿用现有约定，如果没有约定，就放在合理的地方，并说明放在了哪里。
