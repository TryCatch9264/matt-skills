# 阶段边界

**阶段**是会话里的一个工作块：拷问、实现、QA。定义有意保持模糊：当你想“好，这件事做完了”，一个阶段就结束了。

**阶段边界**是两个阶段之间的间隙，而这个决定只属于那个位置。阶段中途没有决定可做：要么继续，要么把剩下的工作拆给子代理。在阶段中途压缩上下文，代理会丢掉线索。

## 五个选项

| 选项         | 它做什么                                                       |
| ------------ | -------------------------------------------------------------- |
| **继续**     | 留在当前会话里。完全不切换上下文。                             |
| **`/clear`** | 清空上下文窗口，从零开始。                                     |
| **`/handoff`** | 写一份可移走的 markdown 文件，用它把会话种到任何地方。       |
| **子代理**   | 把任务送到它自己的上下文窗口，拿回一份报告。                   |
| **`/compact`** | 压缩当前上下文，用摘要种出一个新会话。                       |

## 判断树

在阶段边界处从上往下走。第一个回答“是”的胜出。

**1. 你可以在当前会话里继续吗？** 有两种情况答案是“是”：下一阶段需要本阶段作为**一手来源**，或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）还够装下下一阶段。拷问 → 实现是标准的“是”：实现需要原始推理，而不是它的摘要。继续不花什么代价，也不丢什么，所以先把它排除掉。

**2. 当前上下文和接下来要做的事无关吗？** 这个会话里的所有内容（探索、决定、死路）都可以丢掉吗？如果是，就 **`/clear`**。这是棋面上最便宜的一步：不花时间，还把所有窗口空间交还给你。`/clear` 也不是终点：旧会话仍然可以恢复。

这一步判断错误的代价是单向的。把一个*相关*的上下文清掉，你就丢掉了当初那么做的**原因**，之后再怎么读 diff 也找不回来。

**3. 你需要交接吗？** `/handoff` 的适用范围很窄。只有在你属于下面几种情况时才需要：

- 换到**新的 harness**（Agent 运行器，比如 Claude → Codex），
- 换到**新目录**或新仓库，
- 把工作交给**同事**，
- 或者要分出一条**在阶段中途**发现的支线任务，又不打断手上的事。

这份清单就是全部条件。`/handoff` 换来的是**可携性**：一份能带走的文件。如果没有东西要带走，就不需要它。

**4. 这个任务能脱手（AFK）完成吗？** 它界定得是否足够紧凑，能在你离开键盘、不做引导的情况下跑完？如果可以，就交给**子代理**，当前会话原样不动。自动审查是标准用例：代理读 diff 并汇报，过程中不需要你。

**5. 否则，`/compact`。** 上下文相关、同一个 harness、同一个目录，而且你需要留在循环里：判断树就落到这里，而且经常落在这里。给它一条指令（`/compact we're going to QA this area`），让摘要保留下一阶段需要的东西。

`/compact` 是**默认选项，不是第一选择**。它排在最后，是因为它上面的四个问题都更便宜或更精确。人们一上来就用它时的失败情形是：新会话对某个被摘要压平的决定自信地做出错误判断。

## 一手来源与二手来源

除了**继续**，每个动作都把**一手来源**变成**二手来源**：真实发生过的会话，被它的摘要取代。这个取舍的形状始终一样：

| 来源                                | 信息 | 噪声 | 回旋余地 |
| ----------------------------------- | ---- | ---- | -------- |
| 一手（继续）                        | 完整 | 多   | 少       |
| 二手（`/compact`、`/handoff`）      | 有损 | 少   | 多       |

这就是为什么第一个问题排在最前。只有当留下来的代价高于它省下的东西时，你才需要付出有损的代价。

## 这些都是判断

这些问题不是客观题：每一条都有品味成分，同一个边界在不同日子可以走向两个方向。价值在于**按顺序**提问，并且在边界处问，而不是在工作中间问。
