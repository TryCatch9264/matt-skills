# 分诊标签

这些技能用五个规范的分诊角色来说话。本文件把这些角色映射到本仓库议题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估这个议题 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已经写清楚，可以交给离线（AFK）agent |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现 |
| `wontfix`                  | `wontfix`            | 不予处理 |

当某个技能提到一个角色时（例如“打上可交给 AFK 的分诊标签”），使用本表中对应的标签字符串。

请把“我们跟踪器中的标签”这一列改成你实际使用的词汇。
