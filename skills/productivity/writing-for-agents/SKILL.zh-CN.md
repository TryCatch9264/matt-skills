写任何由代理阅读的文档时的参考：一个技能、一份 `AGENTS.md` / `CLAUDE.md`、一份通过指针抵达的文档。打包方式不同，写法不变：同样的几根杠杆让每一份都可预期，因为代理每次运行走的是同一个*过程*，而不是产出同样的结果。

当你写的是技能时，读 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.zh-CN.md)，了解 frontmatter、调用方式的选择和导航型技能。

## 上下文指针

**上下文指针**是保存在代理上下文里的一条引用，指向上下文之外的材料，并写明抵达它的条件。技能的 description 就是一个；`AGENTS.md` 里指向某份文档的一行是同一个东西。决定代理何时抵达该材料、以及有多可靠的，是指针的*措辞*，不是它指向的目标。必备的目标配一个措辞薄弱的指针，就是一处不稳定性缺陷：先把措辞磨利，只有磨不利时才把材料内联进来。

指针做两件事：说明材料是什么，并列出应当触发抵达它的**分支**（分支指文档处理的一个独立情形，不同运行会走不同路径穿过它）。常驻加载的指针每个字每一轮都在付费，所以它比正文更值得狠剪：

- **把领头词放在最前面**：指针就是在那里做触发工作。
- **一个分支一个触发器。** 用来重命名同一分支的同义词，是同一个分支写了两遍；合并它们，只保留真正不同的分支。
- **删掉正文已经承载的身份信息。**

## 两种负载

你添加的每份文档和每个指针，都在花掉两种预算之一：

- **上下文负载**是常驻加载材料占用代理上下文窗口的代价：一行 `AGENTS.md`、一个技能 description，任何每一轮都待在上下文里的东西，无论触发与否都在消耗 token 和注意力。
- **认知负载**是人的代价：存在哪些文档、什么时候该用哪一个。人是那个索引。这不是要尽量压缩的成本：它是人保有主动权的价格；在人需要判断的地方花它，在人不需要判断的地方去掉它。

只通过指针抵达的材料，用指针自己那一行的代价换掉了上下文负载；完全没有指针的材料，则完全靠认知负载承载。

## 信息层级

一份文档由两类内容构成：**步骤**（代理按顺序执行的动作）和**参考**（按需查阅的定义、规则、事实）。两者自由混用：全是步骤（一份操作配方）、全是参考（一份审查的规则、本技能），或者两者都有。核心决定是每一块在**信息层级**上的位置：这是一把梯子，按代理需要该材料的即时程度排序：

1. **文件内步骤**是第一级：代理按顺序做什么。
2. **文件内参考**按需查阅。常常合理地是一组平级的同类项（一条审查的每条规则都在同一级），这是合理的安排，不是问题。
3. **外置参考**被推到单独文件里，通过上下文指针抵达，只在指针触发时加载。范围从同一目录下的兄弟文件，一直到完全外部的参考，可以住在任何地方，任何文档都能指向它。

往下推得太少，顶层就臃肿；推得太多，就藏起了代理真正需要的材料。这个张力就是整个决定。

**渐进披露**是沿梯子往下走（移出主文件、放到指针后面），让顶层保持可读。它首先不是 token 优化：它是保护层级的方式。分支是最干净的披露判据：每个分支都需要的就内联，只有部分分支才触及的推到指针后面。当文档里有步骤时，本该外置的文件内参考会把这些步骤埋掉，让代理注意到它们变成抛硬币：这是影响稳定性的杠杆，不只是可读性。

**就近聚合**是文件内的配套做法：梯子决定一块内容放在多下面，就近聚合决定它放在那里时旁边放什么。把一个概念的定义、规则和提醒放在同一个标题下，而不是散落各处，这样读一部分就把它邻近的内容一起带进来。判据：文档应当读起来像为代理写的文档。聚合的材料读起来是这样；散乱的材料不是。（这与重复不同：重复是把一个意思写在两个地方；散乱是把一个意思碎成很多块。）

**篇幅失控**是这里的失败模式：文档单纯太长，即使每一行都是活的、独一无二的。注意力在冗余中变薄，多出来的每一行都多一份维护相关性的负担。解法是梯子：把参考外置到指针后面，按分支或按顺序拆分，让每条路径只承载自己需要的东西。

## 步骤与完成标准

每个步骤都以一条**完成标准**结束，也就是告诉代理工作已完成的条件。两个属性让它成为杠杆：

- **清晰度**：代理能不能分辨做完和没做完？含糊的边界（“已达成理解”）会招来**提前完成**：在真正做完之前就结束这一步，注意力滑向*“做完了”*。还看得见的后续步骤（**完成后步骤**）提供拉力；完成标准的清晰度是阻力。防守顺序：**先把边界磨清楚**（局部且便宜）；只有当它确实模糊不清、*而且*你确实观察到赶工，才通过拆分序列把后面的步骤藏起来。隐藏只在真实的上下文边界上有效（交接或派发子代理；内联调用会让后续步骤留在上下文里，什么都没清掉）。
- **要求强度**：它要求多少。“每一个被修改的模型都交代过”逼出细致的工作，“产出一份改动清单”则不会。要求强度驱动**基础功**（代理在工作范围内做的挖掘，它隐含在措辞里，而不是写成单独一个步骤），而且它不受步骤限制：“每条规则都应用了”约束一整片平级参考，正如“每个步骤都完成”约束一个序列，这就是一篇全是参考的文档仍然带有彻底性门槛的方式。

最强的完成标准既可核验，又覆盖穷尽。

## 什么时候拆

把一份文档拆成两份会花掉两种负载之一，所以只有当切分值得时才拆：

- **按顺序拆**：当后续步骤诱使代理赶工眼前这一步时，把一串步骤拆开。把它们挡在视野之外，能让代理在当前任务上多下功夫。注意反过来也有风险：合并序列会让每个步骤的后续步骤暴露给它，招来提前完成。
- **按调用方式拆**，仅针对技能：见 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.zh-CN.md)。

## 领头词

**领头词**是模型预训练里已经存在的一个紧凑概念，代理在运行文档时用它思考（_课_、_战争迷雾_、_曳光弹_）。作为词元反复出现，而不是作为句子重复，它会积累出一个分布式的定义，用最少的 token 锚住一整片行为，靠的是调动模型已有的先验。自己造词也可以，前提是定义清楚，但生造词调动不了任何先验：你用定义所需的 token 付出了预训练词免费给你的东西；所以先用已有的词。

它在两处锚定。在正文里锚定*执行*：词一出现，代理每次都去拿同一套行为；在平级参考里，它把注意力聚到某一类该找的东西上。在指针里锚定*调用*：当同一个词出现在你的提示、文档和代码库里时，代理会把这份共同语言与材料关联起来，更可靠地抵达它。

主动寻找用领头词重构的机会。在三处铺开写的三元组，一个指针花一整句去指出的一个想法。每一段都在请求被收成一个词元：

- “快、确定、低开销” → _紧_（一条*紧*的回路）。
- “一条你信得过的回路” → _红_，把模糊的门槛变成二值的可观察状态（回路在这个缺陷上变*红*，或者不变）。

你赢两次：token 更少，钩子更锐利，代理可以把思考挂上去。可以假定每份文档里都有能被领头词取代的重复表述。去找出来。

**否定**是这根杠杆旁边的失败模式：靠禁止来引导，会把被禁的行为拖进上下文，让它*更*容易被想到，而不是更少。_别想大象_，脑子里就全是大象；否定是一个弱修饰，压不过被强力激活的概念，于是那条禁令有一半读起来像“去做这件事”的指令。要提示**正面**：说出目标行为（“写单行注释”），让被禁的那种根本不被提起。禁令只有在它是你无法正面表述的硬护栏时才值得存在；即便那时，也要配上正面目标，让注意力落在该做的事上。

## 精简

- 每个意思只放在**单一事实来源**：一个权威的位置，这样改变行为就是改一处。**重复**（同一个意思出现在多于一个地方）耗费维护成本和 token，还会把一个意思在层级上的显眼程度抬过它真正的等级。（它是领头词的意外反面：后者有意重复词元，从不重复意思。）
- **环境**也是事实来源（`package.json` 脚本、配置文件、目录布局、`--help` 输出），复述它的文档是一层**缓存**：一次查找的副本，只有当查找代价高时才值回它的负载。缓存那些代理靠看找不到的东西：没写下来的约定、选择背后的理由、没有任何配置会承认的坑。单文件、单命令就能查到的，留给环境，它们在那里不会过时。
- 逐行检查**相关性**：它还与文档要做的事有关吗？一行会因为从不切题（纯铺陈，或者本该外置的分支）而失去相关性，也会因为它描述的行为或世界发生变化而过时。更短的文档更容易保持相关。没有精简的纪律，默认的归宿是**沉积**：陈旧的层级沉淀下来，因为添加感觉安全、删除感觉冒险，直到你不得不钻孔穿过它们去找还有效的部分。
- 逐句寻找**无效指令**：模型本来就默认遵守的指令，花了负载却什么都没说。判据（它相对默认行为改变了什么吗？）是相对模型的，不是相对读者的：两个人对某条是否算无效指令有分歧，其实是对默认行为有分歧，靠运行文档来解决，不靠争论。当一句话不合格，就整句删掉，而不是从里面删几个词。这个判据也用来评价领头词：弱到压不过默认的词（代理本来就大致仔细时写*要仔细*）就是无效指令，修法是换更强的词（_不留余地_），而不是换一种手法。
